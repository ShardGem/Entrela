# Galeria do Entrela 0.27.0

84 capturas PNG sem perdas, renderizadas diretamente no Qt. Janela principal: 1440 × 900 pixels lógicos, escala 2×, fonte 15 px.

Os cenários foram executados em armazenamento temporário, com sementes registradas. São demonstrações do aplicativo; não substituem os experimentos do TCC. A splash e o diálogo de configurações conservam seus tamanhos próprios. O relatório aparece integrado ao caderno.

As capturas de texto ampliado usam janela de 1024 × 768 pixels lógicos e fonte de 24 px. Tema, tamanho do texto, resolução e escala de cada imagem ficam registrados no manifesto.

Clique nos nomes para abrir os arquivos originais. [Manifesto e hashes](manifesto.json) · [Configurações e resultados dos cenários](cenarios.json) · [Estudos calculados](estudos.json).

## Como regenerar

A partir da raiz do projeto:

```bash
python scripts/capture_gallery.py --output docs/screenshots/0.27.0 --scale 2 --width 1440 --height 900
```

Use `--overwrite` somente para atualizar os arquivos gerados. Nenhum experimento ou preferência pessoal é lido. A validação destas imagens utiliza Qt offscreen no Linux; a revisão nativa no Windows permanece pendente.
